# 레퍼런스 분석 — 제품 필름형 (AI 가시성 SaaS 프로모, 레퍼런스 6) (2026-11-05)

> 요약: 37.6초 세로 SaaS 프로모의 프레임 단위 분석. 흰 화면과 다크 그라데이션을 하드컷으로 교대하고, 자막 대신 고정 헤드라인 한 줄과 상시 로고로 "차분하고 비싼" 감도를 만든다. 샷 리스트, 감도 측정값, 재현 규칙 12개, 엔진에 없는 것 명세. "이런 고급 프로모 / 제품 필름 / 다크·화이트 교대 / B2" 요청에 연다.

**표기**: `(측)` = 스크립트로 잰 값. `(판)` = 눈으로 본 판단. 좌표는 원본 720×1280 을 재서 ×1.5 한 1080×1920 환산값이다(따로 적지 않으면). 프레임 번호는 1부터, 초 = (프레임−1)/29.97.
**주의**: 이 문서는 스타일·구조의 분석이다. 레퍼런스의 브랜드명·로고·고객사 로고·문구·인물·사진은 재사용하지 않는다. §3 의 원문은 기록용이다.

## 결론 (먼저 읽을 것)
1. **유형: 서사형(B)의 새 하위 유형 "B2 제품 필름형"을 제안한다.** 구조는 B(문제→해결→시연→결과→CTA)지만 `product-demo-30/40` 규격을 어기고(장면 8개, 최장 7.7초, 총 1125f), 기능을 6개 나열하고, 내레이션+BGM 이 전제이며, 자막이 "헤드라인"이다. 근거 §7.
2. **감도의 정체는 "절제"다. 숫자로는 네 가지다.** 흰 샷에서 흰 픽셀 86~97%, 채도 있는 픽셀 1.6% 이하(측). 움직임은 전부 감속이고 오버슈트 0(측). 전체 프레임의 39.5%가 완전 정지(측). 헤드라인은 애니메이션 없이 0프레임에 바뀐다(측).
3. **명암 교대가 서사를 나른다.** 하드컷 5회는 전부 흰↔다크 전환이고(측), 다크 = "환자가 AI에게 묻는 세계", 흰색 = "우리 제품 안"이다(판). 시간 비율 흰 68.3% / 다크 31.7%(측).
4. **핵심 장치는 콜백이다.** 같은 프롬프트가 2.6~9.4초와 19.5~22.3초에 두 번 나오고, 두 번째에는 답이 "우리 병원"이 된다(판). 기능 설명이 아니라 이 결과가 영상의 설득이다.
5. **엔진에 없는 것이 많다.** 씬 타입 5종, 레이아웃 1, 팔레트 2, 상시 로고, 이징 2종, 오디오, 폰트, 프로필. §9.3. 그중 **오디오는 이 감도의 절반**이고 지금 엔진에 필드 자체가 없다.

### 9.2 새 씬 타입 명세 (값은 1080 기준, 30fps)
**`select-hook`**: `lines: [string, string]`, `selectLine: 1`.
블록 상승 114px·14f(easeOutCubic), 2행 opacity 0→1 f1~6, 선택 영역 왼→오 22f(easeOutQuint), 양 끝 핸들 점 지름 약 12px, 색 `#B2D1FC`/`#3B7AD7`. 레퍼런스의 문구가 아니라 **대상 고객이 실제로 치는 문장**을 넣는다.

**`ai-answer`**: `prompt`, `answer[]`(강조 구절 지정), `cards[]`(제목·메타·이미지 2·버튼), `mode: "list" | "tilt"`, `startTyped?: 0~1`.
- pill 진입 상승+페이드 8f → 마스크 타이핑 약 18f → 답변 공개 전 pill 상승 260px·20f → 답변 줄 순차 공개 10f
- 카드 상승 20f(easeOutQuint) + 뒤 레이어 blur 약 10px·밝기 0.4 → 체류 → 다음 카드 슬라이드 18f, 간격 1082px(easeOutCubic)
- `tilt`: `perspective(1600px) rotateX(37deg)` 상승 18f, 이후 45f 스케일 1→0.92 표류, 왼쪽 아래 녹색 글로우 추가
- 카드 사진 없으면 그라데이션 자리표시. 지어낸 수치·평점은 `sample: true` 로 표시(런북 C 실패 방식과 같은 기준)

**`ui-stage`**: `frame: "soft" | "browser" | "panel"`, `panels[]`, `zoom?: {at, to: 1.82, frames: 26}`(ease-in-out, 틀 고정·내용만), `pip?: {src, d: 210}`(줌 때 150 으로).
패널 종류(모두 코드 생성):
- `line-chart`: 큰 % 카운터 + 선 드로잉 + 동행 툴팁 + `+N%p` 칩. 40f
- `rank-list`: 순위 7행, 넓은 행 간격에서 좁혀지며 진입(약 25f)
- `doc-columns`: 2열 카드, 반대 방향 스크롤 75px/s
- `detail`: 표 + 막대 드로잉
- `multi-line`: 5~6색 곡선(이 패널만 다색 허용) + 커서·툴팁

패널 전환은 슬라이드 15f, 간격 1100px. 또는 `cut: true` 로 하드 스왑. 내용은 프레임 안에서 잘린다(전부 보여주지 않는다). 녹화 소재가 있으면 `src` 로 대체.

**`cta-marquee`**: `icon`, `lines[2]`, `button`, `rows: string[][3]`.
아이콘 126, 문구 약 48px, 버튼 729×155 `#101010`, 스케일 1↔0.914 삼각파 32f, 행 y 1037/1179/1322, 속도 −15/+22.5/−15 px/s. 고객사 로고는 **허락받은 실제 로고만**, 없으면 이 행을 빼고 CTA 를 위로 올린다. 없는 실적을 꾸미지 않는다.

**`logo-outro`**: `logo`. 중심 (540, 879), 스케일 1.12→1 12f(easeOutCubic) 후 72f 동안 1→0.92 선형. 다크 배경.

### 9.5 오브제 생성 지침 (SVG/CSS)
- UI 는 라이브러리 없이 CSS 로 그린다. 선 1.5px, 글자는 회색 2단계만, 면은 흰색·`#E5ECF2` 만
- 그래프는 SVG path + `strokeDashoffset`. 색 1개
- 유리 카드는 CSS `backdrop-filter` 대신 불투명에 가까운 `#1D1D1D` + 1.5px 테두리. 렌더 안정성 때문이다(판)
- 글로우는 `radial-gradient` 원 하나. 블룸 금지
- 아이콘은 선 심벌 1종. 레퍼런스 심벌을 따라 그리지 말고 **제품 자체 로고**를 쓴다. 그림자·그레인·노이즈 넣지 않는다

### 9.6 제작 세션의 권장 순서
1. 무음으로 흰/다크 8막 스켈레톤과 `brand`·`headline` 부터 만들어 규칙 1~7 을 확인한다. 이 단계에서 감도의 70%가 판가름 난다(판)
2. `ui-stage` 패널, `ai-answer`, 나머지 씬
3. 오디오. 내레이션 길이가 씬 길이를 정한다

## 10. 측정 못 했거나 확신이 낮은 것
- **내레이션 내용**: 음성 인식 도구가 없어 받아 적지 못했다. 헤드라인과 같은 말인지 모른다
- **PiP 립싱크**: 입 영역 움직임과 음성 에너지 상관 0.24, 판정 불가. 내레이션이 그 인물 목소리인지 모른다
- **구절 경계**: 음악이 섞여 근사. BGM 분리를 못 했다
- **효과음**: 없다고 단정 못 한다. 믹스에 묻혔을 수 있다
- **서체명·실제 글자 크기**: 잉크 높이만 쟀다. 크기·자간은 추정
- **3D 값**: 2점 추정. `perspective`·`rotateX` 는 조합이 여럿 나온다
- **블러 반경, 유리 면 투명도**: 판단값
- **소재 구분**(녹화 vs 재구성 UI): 판단이다
- **그레인 없음**: 395kbps 재압축본이라 원본의 미세 그레인이 지워졌을 수 있다
- **+0.9 dBFS 트루피크**: 원본 마스터인지 재인코딩 결과인지 모른다
- **PiP 지름**: 눈금 판독(±8px)
