# 레퍼런스 분석 — "스마트홈" 앱 화면 녹화형 (2026-10-30)

> 요약: 실제 앱 화면 녹화를 폰 목업에 담고 상단 자막만 바꾸는 53초 워크스루. 컷 0회지만 전시형이 아니다. 앱·서비스의 실제 사용 흐름을 보여줄 때 연다.

## 결론 (먼저 읽을 것)
1. **컷 0회인데 53초다.** 기존 분류(컷 0 + 12초 이하 = 전시형)로는 안 잡힌다.
   화면이 안 바뀌는 게 아니라 **녹화가 계속 흐르기 때문에** 컷이 없는 것이다.
2. **소재가 코드가 아니라 실제 화면 녹화다.** 레퍼런스 2(카드형)와 구조는 같지만 만드는 방법이 완전히 다르다.
   → 분류에 **소재 축**이 필요하다는 걸 이 영상이 드러냈다 (`runbooks/레퍼런스분석_절차.md` §2.5).
3. 화면 구성은 **상단 자막 + 폰 목업 하나**. 그 외에 아무것도 없다.
4. 자막이 `라벨: 설명` 형식이다 — "홈: 우리 집 3D 평면도", "기기: 월패드 기기가 그대로".
   앱의 **탭 이름을 라벨로 쓰면** 시청자가 지금 어느 화면인지 바로 안다.
5. 인트로만 폰 2개를 나란히 놓고, 오른쪽에 **실사 촬영**(천장 조명이 켜지는 장면)을 넣었다.
   앱 화면과 실제 세계를 한 프레임에서 연결하는 장치다.

## 1. 포맷·타이밍
| 항목 | 값 |
|---|---|
| 해상도 / fps / 길이 | 720×1280(9:16) / 30fps / **53.46초** |
| 하드컷(0.25) | **0회** |
| 변화(0.03) | 24회 — 자막 교체와 앱 화면 전환이 섞여 있다 |
| 자막 교체 주기 | 약 2~4초 (페이드) |
| 인트로 | 0~4.5초(타이틀 3줄 + 폰 2분할, 오른쪽은 실사) |

**관찰**: 자막 주기가 레퍼런스 2(1~1.5초)보다 **두 배 이상 길다.**
녹화 화면은 그 자체로 볼 것이 많아 자막을 자주 바꾸면 시선이 분산된다.

## 3. 색
| 이름 | 값 | 쓰임 |
|---|---|---|
| 배경 | `#FDFFFF` (거의 순백) | 전체 |
| 자막 본문 | 거의 검정 | 상단 자막 |
| 자막 강조 | 파랑 `#3B5BFE` 계열 | "쉽게", "바로", "연동", "4개" 등 핵심어 |
| 폰 프레임 | 흰색 + 옅은 그림자 | 목업 |

**색이 배경·검정·파랑 3개뿐**이다. 녹화 화면이 이미 복잡하므로 프레임은 최대한 조용하게 둔다.

## 4. 자막 작성 방식 (가져갈 것)
| 패턴 | 예시 |
|---|---|
| `탭 이름: 그 화면이 뭔지` | `홈: 우리 집 3D 평면도` / `기기: 월패드 기기가 그대로` / `자동화: 루틴을 만드는 곳` |
| 조건절 + 결과 | `우리 아파트가 연동 단지라면` → `평면도를 그대로 불러오고` |
| 동작 나열 | `외출: 불 끄고 엘리베이터 호출` / `귀가: 불 켜고 환기까지` |

- 강조색은 **한 자막에 한 단어**만. 전부 강조하면 아무것도 강조되지 않는다.
- 자막이 화면을 **해설**하지 않고 **이름 붙인다**. 보이는 걸 다시 말하지 않는다.

## 5. 왜 이 형식이 되는가
- 실제 앱이 이미 완성돼 있으면 **그리는 것보다 찍는 게 빠르고 정확하다**.
- 화면 녹화는 "진짜 돌아간다"는 증거다. 목업은 그 증거가 약하다.
- 대신 **녹화 품질이 영상 품질의 상한**이 된다. 끊기거나 지저분한 녹화는 편집으로 못 살린다.

## 6. 우리 엔진으로 만들려면 (없는 것)
| 필요한 것 | 지금 상태 |
|---|---|
| **`screen-record` 씬** — 폰 프레임 + 화면 녹화 영상 임베드 + 구간 트림 | 없음. `@remotion/media` 의 `<Video>` + 폰 프레임으로 가능 |
| **상단 자막 스타일** — 흰 배경 위 검정 + 단어 단위 강조색 | 부분적. `plain` 스타일은 있으나 자막 Y 가 레이아웃 고정이라 **상단 배치가 없다** |
| 폰 목업 프레임(라운드·그림자) | 없음 (`browser-mock` 은 데스크톱 창이다) |
| 인트로 2분할(앱 화면 + 실사 B롤) | 없음 |
| 거의 순백 배경 팔레트 | 없음 (`pastel` 은 그라데이션이 있다) |

→ 최소 구현: **`screen-record` 씬 + 자막 상단 배치 옵션** 둘이면 이 형식의 본문을 재현한다.
녹화 파일은 `engine/public/screens/*.mp4` 로 두고 spec 에서 경로·트림 구간을 가리킨다.

## 7. 레퍼런스 2(카드형)와의 차이
| | 레퍼런스 2 카드형 | 이 영상 녹화형 |
|---|---|---|
| 소재 | 코드로 그린 UI | **실제 화면 녹화** |
| 자막 위치 | 카드 아래 | **상단** |
| 자막 주기 | 1~1.5초 | 2~4초 |
| 길이 | 32.6초 | 53.5초 |
| 만드는 법 | spec 작성 → 렌더 | **녹화 → 트림 → 자막 얹기** |

구조는 같다(항목 반복). **소재와 제작 방식이 다르다.**
