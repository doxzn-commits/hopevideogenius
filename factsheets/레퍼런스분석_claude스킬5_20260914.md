# 레퍼런스 분석 — "클로드 코드 스킬 5개" 숏폼 (2026-09-14)

> 요약: Claude로 모션그래픽을 생성한 레퍼런스 숏폼을 프레임 단위로 분해한 수치·레이아웃·모션 모티프 목록. 스타일을 재현하거나 새 씬 타입을 설계할 때 연다.

## 결론 (먼저 읽을 것)
- 포맷: **720×1280(9:16), 30fps, 56.7초, 컷 30개 → 평균 샷 1.9초**. 자막 한 구절 = 한 샷에 가깝다.
- 레이아웃은 3종뿐이다: **split**(상단 그래픽 + 하단 토킹헤드), **full-graphic**, **full-face**(사람 풀샷). 이 3개가 엔진의 `layout` 값이다.
- 모든 그래픽은 "카드 1장 + 배경 글로우 + 자막" 구조. 카드 안 요소는 10여 개 모티프의 조합이다(아래 표).
- 항목(스킬)마다 **배경 팔레트를 바꿔 챕터를 구분**한다. 챕터 번호 칩(`02 / 05`)이 같이 붙는다.
- 레퍼런스 원본: 로컬 다운로드 mp4(레포에 없음, .gitignore), Threads @gasket_love 게시물(DdJ46yGGyW9) — "made with claude opus 5 High 100%", 모든 모션은 코드, After Effects 미사용이라고 명시.

## 1. 타이밍
컷 검출(ffmpeg scene>0.25) 타임스탬프(초):
`0.1 1.83 2.83 4.4 5.1 6.73 7.87 9.9 12.2 13.37 14.53 16.47 19.7 22.0 24.1 28.23 28.87 35.1 36.53 37.1 38.17 39.97 42.4 44.03 46.23 47.73 48.53 50.03 51.87 54.03`
- 짧은 샷 0.6~1.2초(강조 한마디), 긴 샷 3~6초(그래픽 전개가 여러 단계일 때).
- 한 샷 안에서도 그래픽은 1~2초 간격으로 다음 단계로 진행한다(타이핑 → 결과 → 하이라이트).

## 2. 레이아웃 수치 (1080×1920 환산, 원본×1.5)
| 요소 | 값 |
|---|---|
| split: 토킹헤드 영역 상단 | y≈1170 (61%), 상단 모서리 라운드 큰 반경(≈120px) |
| split: 그래픽 카드 영역 | y≈80~1080, 좌우 여백 ≈60px |
| 자막 기준선 | split: y≈930~960(48~50%, 카드 하단과 겹침) / full-face: y≈1120(58%) |
| 자막 폰트 | 흰색 굵은 고딕 ≈60px, 짙은 외곽선+그림자, 강조어 노랑(#FFD84D)·파랑(#3AA0FF) |
| 카드 | 라운드 ≈36px, 1px 반투명 테두리, 배경보다 약간 밝은 반투명 면, 부드러운 드롭섀도 |
| 카드 헤더 | 신호등 점 3개 + ✳ 아이콘 + 대문자 자간 넓은 라벨(CLAUDE CODE) + 오른쪽 pill 칩(24 SKILLS) |
| 라벨 타이포 | 대문자, 자간 0.15em 이상, 기하학 산세리프(Montserrat 계열) |
| 명령줄 | 모노스페이스, `>` 프롬프트, 블록 커서 |

## 5. 전개 구조 (대본 템플릿)
1. 훅(0~5초): "~가 처음이라면 / 이 N개는 / 무조건 설치해야 돼요"
2. 전체 목록 한 장(설치 리스트) → "이것만 설치하면 / 필요가 없어요"
3. 항목 × N: `N 번째는` → 이름 카드 → 출처/근거 → 문제 상황 → 해결 시연 → 효과 수치
4. 요약 한 장(아이콘 5개 한 줄) → "한 번에 설치하고"
5. CTA: 문서화 자료 예고 → 팔로우 → 댓글 키워드 → DM 전송 목업

ffmpeg -i in.mp4 -vf "select='gt(scene,0.25)',showinfo" -an -f null - 2>&1 | grep -o "pts_time:[0-9.]*"
