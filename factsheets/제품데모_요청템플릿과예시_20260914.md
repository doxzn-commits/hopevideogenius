# 제품 데모 영상 — 요청 템플릿과 작성 예시 (2026-09-14)

> 요약: 제품 데모 영상을 의뢰할 때 채우는 입력 항목 원문과, 그로블(디지털 상품 판매 플랫폼) 예시 대본. 기획을 시작하기 전 어떤 정보를 받아야 하는지 확인할 때 연다. 절차는 runbooks/제품데모영상_기획절차.md.

## 1. 요청 템플릿 (그대로 복사해 채운다)

```
다음 제품의 UI 모션그래픽 홍보영상 대본과 제작 명세를 작성해줘.

[제품 정보]
- 제품명:
- 제품 소개:
- 주요 고객:
- 고객이 겪는 문제:
- 소개할 핵심 기능 하나:
- 사용 전 방식:
- 제품을 사용하는 과정:
- 사용 후 결과:
- 경쟁 방식과 다른 점:
- CTA:
- 영상 길이:
- 화면 비율:
- 브랜드 컬러:
- 원하는 분위기:
- 반드시 보여줄 화면:
- 사용 가능한 에셋:
- 내레이션 사용 여부:

[제작 조건]
- 실제 제품에 존재하지 않는 기능은 만들지 말 것
- 첫 3초 안에 고객 문제를 제시할 것
- 한 장면당 화면 문구는 최대 두 줄
- 장면별 시간을 정확히 배분할 것
- UI, 커서, 클릭, 화면 전환 동작까지 구체적으로 작성할 것
- 마지막에 구현용 spec(JSON)을 포함할 것
```

**필수 5개**: 제품명 / 대상 고객 / 핵심 기능 하나 / 사용 전→후 / CTA.
나머지는 합리적으로 가정하고, 가정한 내용을 결과 맨 위에 적는다.

## 2. 작성 예시 — 그로블 (40초 / 7장면)

입력 요지: 디지털 상품(강의·전자책·템플릿) 판매 플랫폼. 1인 창작자 대상.
문제 = AI로 상품을 만들어도 판매 페이지·상품 정보는 직접 등록해야 함.
핵심 기능 하나 = AI 도구에서 상품 생성과 등록을 연결하는 MCP.
차별점 = 브라우저를 대신 클릭하는 자동화가 아니라 서비스에 직접 연결.
CTA = 지금 그로블 MCP 연결하기. 컬러 = 민트·아이보리·블랙.

| 장면 | 시간 | role | 화면 문구 | 내레이션 | 모션 |
|---|---|---|---|---|---|
| 1 | 0~4초 | hook | 상품은 AI로 만드는데 / 등록은 아직 직접 하시나요? | "상품은 AI로 만드는데, 등록은 아직 직접 하고 계신가요?" | 첫 줄 아래에서 24px 이동 등장, 둘째 줄 0.3초 뒤 강조색 |
| 2 | 4~9초 | problem | 복사하고, 입력하고, 다시 확인하고 | "완성된 내용을 복사하고, 판매 페이지에 다시 입력하는 과정." | 커서가 입력란 3개를 빠르게 오가며 반복 작업 시각화 |
| 3 | 9~14초 | solution | 이제 AI와 그로블을 연결하세요 | "이제 AI와 그로블을 직접 연결해 보세요." | 두 로고 사이 연결선이 그려지고 완료 표시 |
| 4 | 14~21초 | demo | (채팅) 취업 준비생을 위한 이력서 첨삭 상품을 만들어줘 | "판매할 상품을 설명하고, 상세페이지를 만들어 달라고 요청하면," | 타이핑 후 전송 클릭, 클릭 위치에 민트 글로우 |
| 5 | 21~29초 | demo/result | 상품 정보와 상세페이지 생성 | "상품 정보와 상세페이지가 만들어지고, 등록까지 이어집니다." | 상품명·가격·소개·버튼이 0.15초 간격으로 순차 등장 |
| 6 | 29~35초 | differentiation | 화면을 대신 클릭하는 방식이 아니에요 | "브라우저 화면을 대신 클릭하는 자동화가 아닙니다." | 커서 아이콘이 사라지고 직접 연결을 강조 |
| 7 | 35~40초 | cta | 만드는 것부터 판매까지, AI와 함께 / 그로블 MCP 연결하기 | "만드는 것부터 판매까지. 지금 그로블 MCP를 연결해 보세요." | CTA 버튼이 102%로 한 번 커진 뒤 2초 유지 |

### 이 예시에서 가져갈 것
- **2번 장면의 반복 작업 시각화**가 문제를 가장 빠르게 전달한다. 말로 설명하지 않고 커서 움직임으로 보여준다.
- **6번 장면처럼 "아닌 것"을 먼저 말하면** 차별점이 선명해진다("대신 클릭하는 자동화가 아니다").
- 내레이션과 화면 문구가 **다른 문장**이다. 화면은 짧게, 내레이션은 문장으로.
- 이 예시는 16:9 요청이었다. 엔진은 현재 9:16 만 지원한다(`KNOWN-GAPS.md`).
