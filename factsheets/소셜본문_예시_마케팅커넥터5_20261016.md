# 본문 예시 — "Claude 마케팅 커넥터 5개" (2026-10-16)

> 요약: 레퍼런스 영상의 게시물 본문 원문과 줄별 해부(왜 이렇게 썼는지). 본문을 쓸 때 형태를 베낄 원본으로 연다. 절차·규칙은 runbooks/소셜본문_작성절차.md, 영상 분석은 factsheets/레퍼런스분석_마케팅커넥터5_20261016.md.

## 원문

```
Claude로 마케팅한다면 이 5개는 무조건 연결하세요.

1. Bright Data · 경쟁 계정 릴스를 긁어 와서 반응 좋은 순서대로
2. Meta Ads · 광고 소재별 성과 확인, 예산 조정, 광고 켜고 끄기까지
3. Firecrawl · 경쟁사 사이트 가격·상품 정보를 비교표로
4. PostHog · 방문자가 결제 전에 어디서 빠지는지 단계별로
5. Upload-Post · 완성한 릴스를 인스타에 바로 올리고 예약까지

팔로우하고 댓글에 연결 남기면 Claude 마케팅 툴 5개 연결 가이드(연결 방법 + 바로 쓰는 요청문)를 DM으로 보내드려요.

#클로드 #AI마케팅 #마케팅자동화 #클로드커넥터 #메타광고
```

## 줄별 해부

### 훅 — `Claude로 마케팅한다면 이 5개는 무조건 연결하세요.`
- **대상 조건절 + 숫자 + 단정형 명령**의 3단 구성. 23자.
- "~한다면"으로 대상을 거르고, "이 5개"로 분량을 약속하고, "무조건"으로 망설임을 없앤다.
- 성과를 주장하지 않는다("매출이 오릅니다" 같은 말이 없다). 주장하는 건 **행동**뿐이라 검증 부담이 없다.

### 항목 5줄 — `이름 · 결과`
| 줄 | 쓰인 방식 |
|---|---|
| `Bright Data · 경쟁 계정 릴스를 긁어 와서 반응 좋은 순서대로` | 동사로 안 끝내고 "순서대로"로 끊음 — 목록에서 더 빨리 읽힌다 |
| `Meta Ads · 광고 소재별 성과 확인, 예산 조정, 광고 켜고 끄기까지` | 할 수 있는 일을 쉼표로 3개 나열하고 "까지"로 범위를 넓힘 |
| `Firecrawl · 경쟁사 사이트 가격·상품 정보를 비교표로` | **산출물 형태**(비교표)를 명시 — 영상의 결과 패널과 일치 |
| `PostHog · 방문자가 결제 전에 어디서 빠지는지 단계별로` | 도구 용어(퍼널·리텐션)를 안 쓰고 겪는 상황으로 풀어씀 |
| `Upload-Post · 완성한 릴스를 인스타에 바로 올리고 예약까지` | 앞 항목(릴스 제작)과 **연결**되어 목록 전체가 하나의 흐름이 됨 |

공통점:
- 전부 **한 줄**, 28~35자. 줄바꿈이 없어 스캔된다.
- 기능 설명이 아니라 **결과물**이다("수집 도구"가 아니라 "반응 좋은 순서대로").
- 영상에 나온 결과 패널(썸네일 순위 / 표 / 비교표 / 퍼널 / 업로드 예약)과 **1:1로 대응**한다.
  본문만 읽어도 영상이 뭘 보여줬는지 복원된다.

### CTA — `팔로우하고 댓글에 연결 남기면 … DM으로 보내드려요.`
- 요구 행동 **2개**(팔로우, 댓글)에서 멈춘다. 저장·공유·프로필 링크까지 요구하지 않는다.
- 댓글 키워드가 **한 단어("연결")** 이고, 영상 마지막 장면에서 실제로 그 단어를 입력한다 — 본문과 화면이 같은 단어.
- 받을 것을 괄호로 구체화: `(연결 방법 + 바로 쓰는 요청문)`. "가이드"만 적었을 때보다 받을 이유가 분명해진다.
- 경로(DM)까지 적어 다음에 무슨 일이 일어나는지 불확실하지 않다.

### 해시태그 — `#클로드 #AI마케팅 #마케팅자동화 #클로드커넥터 #메타광고`
- 5개. 전부 한글. 구성 = 브랜드(클로드) + 주제(AI마케팅·마케팅자동화) + 세부(클로드커넥터·메타광고).
- 영어 태그 없음. 한국어 피드 대상이라 섞지 않았다.

## 본문 ↔ 영상 대응표
| 본문 | 영상 |
|---|---|
| 훅 한 줄 | 인트로 토글 리스트(5개가 차례로 켜짐) + 상단 문구 "Claude로 마케팅하면 이 5개는 무조건 연결" |
| 항목 N | 커넥터 N 구간(타이틀 → 요청문 → 실행 → 결과), 진행 칩 `N / 5` |
| CTA | 다크 구간(팔로우 → 댓글 "연결" → DM 카드) |
| 해시태그 | 영상에는 없음 — 본문 전용 |

## 다시 쓸 때 바꿀 것 / 유지할 것
- **유지**: 훅 3단 구성, 항목 한 줄·결과 중심, 요구 행동 2개, 키워드 한 단어, 본문과 영상의 단어 일치.
- **바꿀 것**: 도구 이름과 결과. 숫자는 3~5 사이에서 실제 다룬 개수로.
- **하지 말 것**: 항목을 6개 이상으로 늘리기, 성과 수치 추가("3배 빨라집니다"), 키워드를 두 단어로 만들기.
