## 4. 카드 공통 구조
```
┌ 헤더(흰색) ─────────────────────────┐
│ [앱 아이콘]  앱 이름           N / 5 │
│             ● Claude에 연결됨        │
├ 본문(#F7F5F1) ──────────────────────┤
│ [요청문 말풍선 — 사용자가 친 문장]    │
│ [툴 호출 행: 아이콘 tool_name · 대상  실행 중… → ✓ 완료]
│ [결과 패널: 제목 + "예시" 라벨 + 내용]│
└─────────────────────────────────────┘
          카드 아래 자막 (다크, 굵게)
```
- 진행 칩 `N / 5`는 **처음부터 끝까지 같은 자리**에 있어 "5개 중 몇 번째"가 항상 보인다.
- `● Claude에 연결됨`은 녹색 점 + 텍스트. 제품 상태를 한 줄로 보여주는 장치다.
- 결과 패널 우상단 `예시` 라벨 — **실제 데이터가 아님을 표시**한다. 수치를 지어내지 않으면서 결과를 보여주는 방법.

## 5. 결과 패널 4종 (항목마다 다른 그림)
| 커넥터 | 결과 표현 |
|---|---|
| Bright Data | 썸네일 3개 + 순위 배지(1·2·3) + 조회/좋아요 막대 |
| Meta Ads | 표(소재 / 지출 / CTR / 상태) + 토글 스위치, 마지막에 소재 C 토글이 꺼짐 |
| Firecrawl | 비교표(사이트 / 상품 / 가격 / 특징) 행이 순차 등장 |
| PostHog | 가로 퍼널 막대 4단(방문→상품 보기→장바구니→결제), 마지막 막대만 빨강 + "여기서 가장 많이 이탈" 태그 |
| Upload-Post | 업로드 미리보기(썸네일 + 계정명) + "바로 게시" / "예약 · 내일 오후 7:00" |

**공통 규칙: 결과는 "표/막대/썸네일" 중 하나로 한 장면에 하나만.** 숫자는 회색 막대로 가려 구체값을 말하지 않는다.

## 6. 인트로와 CTA
- **인트로(토글 리스트)**: 커넥터 5개가 세로로 나열되고 토글이 `1/5 → 3/5 → 5/5`로 차례로 켜진다.
  헤더 카운터가 같이 올라간다. 영상 전체의 목차 역할.
- **CTA(다크 구간)**: 프로필 카드(팔로우 → 팔로잉으로 상태 변화) → 댓글 시트 → 댓글창에 `연결` 입력 →
  DM 카드(가이드 썸네일 + 부제). **요구 행동이 "팔로우 + 댓글" 두 개인데도** 화면은 한 번에 하나씩만 보여준다.

## 7. 현재 엔진에 없는 것 (이 형태를 만들려면 필요)
| 필요한 것 | 지금 상태 |
|---|---|
| **지속 카드**(여러 씬이 같은 카드 프레임을 공유, 내용만 교체) | 없음. 씬마다 카드가 새로 등장한다 |
| 카드 아래 다크 자막(외곽선 없음) | 없음. 자막은 흰색+외곽선 오버레이 고정 |
| `toggle-list` 씬(토글 순차 ON + 카운터) | 없음 |
| `app-intro` 씬(큰 아이콘 + 역할 한 줄) | `title-card` 로 근사 가능하나 아이콘 중심 레이아웃이 아님 |
| `prompt-run` 씬(요청문→툴 호출→결과 패널) | 없음. **이 형태의 핵심** |
| 결과 패널 4종(썸네일/표/퍼널/업로드 미리보기) | `terminal-list` 가 막대 리스트만 근사 |
| `social-cta` 씬(팔로우·댓글·DM) | 없음 |
| ivory/olive 팔레트 | 없음(pastel 이 가장 가깝지만 그라데이션이 강함) |
| 진행 칩 `N / 5` 자동 계산 | 없음(수동 문자열) |

→ 우선순위: **지속 카드 + `prompt-run` + 자막 스타일 2종**이 먼저다. 이 셋만 있으면 이 영상의 80%를 재현한다.
나머지(`toggle-list`, `social-cta`, 결과 패널 변형)는 그다음.
