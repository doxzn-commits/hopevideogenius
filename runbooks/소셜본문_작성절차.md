# 런북 — 영상 본문(캡션) 작성

> 요약: 숏폼 게시물의 **본문 텍스트**(훅 한 줄 + 번호 목록 + CTA + 해시태그)를 쓰는 절차와 문장 규칙. "본문 써줘 / 캡션 / 인스타 글 / 해시태그" 요청이 오면 연다. 영상 자막은 runbooks/정보전달영상_제작절차.md.

## 왜 따로 쓰나
본문은 영상 자막의 복사본이 아니다. 역할이 다르다.
- **영상 자막** = 소리 없이 보는 사람을 끝까지 붙잡는 것 (한 줄 20자 이하, 한 호흡)
- **본문** = 영상을 다 본 사람이 **저장·댓글·DM**으로 넘어가게 만드는 것 (목록과 CTA가 핵심)

영상이 "무엇을 보여줬는지"라면, 본문은 "그래서 뭘 쓰면 되는지"를 글로 남긴다.

## 구조 (검증된 형태)
```
1) 훅 한 줄        — 대상 + 숫자 + 단정형 ("~라면 이 5개는 무조건 ~하세요")
2) 빈 줄
3) 번호 목록 N개   — "N. 이름 · 그걸로 하는 일(결과 중심 한 줄)"
4) 빈 줄
5) CTA 한 문장     — 행동 + 받을 것 + 받는 방법
6) 해시태그 3~5개
```
- 번호 목록은 **3~5개**. 6개를 넘으면 저장은 늘어도 끝까지 읽히지 않는다.
- 각 항목은 **한 줄**. 줄바꿈 없이 끝나야 목록이 스캔된다.

## 문장 규칙
- 항목은 **도구 이름 + `·` + 그 도구로 "무엇을 하게 되는지"**. 기능 설명이 아니라 결과를 쓴다.
  - ✅ `PostHog · 방문자가 결제 전에 어디서 빠지는지 단계별로`
  - ❌ `PostHog · 제품 분석 및 퍼널 시각화 도구`
- 문장을 **동사로 끝내지 않고 명사·부사로 끊어도 된다**("~순서대로", "~비교표로"). 목록에서는 이게 더 빠르게 읽힌다.
- 훅에는 **숫자와 대상**이 같이 들어간다("마케팅한다면", "이 5개는").
- 과장 금지: "혁신적인", "완전 자동", "무조건 성공" 같은 표현을 쓰지 않는다.
  단, **"무조건 연결하세요"처럼 행동을 단정하는 것은 허용**한다(성과 주장과 다르다).
- 확인되지 않은 수치·성과·후기를 지어내지 않는다. 결과를 보여줄 땐 영상에서 `예시` 라벨을 붙인다.
- 영상 자막에 쓴 문장을 그대로 복사하지 않는다. 같은 내용을 **다른 길이로** 쓴다.

## CTA 규칙
- 요구 행동은 **최대 2개**(예: 팔로우 + 댓글). 그 이상이면 아무것도 안 한다.
- 받을 것을 **구체적으로** 적는다. "가이드"보다 `연결 방법 + 바로 쓰는 요청문`처럼 내용물을 쓴다.
- 받는 방법을 명시한다(댓글 키워드 → DM). 키워드는 **한 단어**로 한다.
- 영상의 마지막 장면과 CTA 문구가 **같은 단어**를 써야 한다(영상에서 "연결"이라고 쳤으면 본문도 "연결").

## 해시태그
- 3~5개. 브랜드/도구명 1~2개 + 주제 2~3개.
- 한글 태그를 우선한다(한국어 피드 기준). 영어 태그를 섞을 거면 1개까지.

## 작성 순서
1. 영상 spec(`engine/specs/*.json`)의 자막을 훑어 **항목 이름과 결과**를 뽑는다.
2. 훅 한 줄을 먼저 쓴다. 영상 첫 3초 자막과 같은 주장을, 더 짧게.
3. 항목을 "이름 · 결과"로 압축한다. 각 줄 35자 이내가 읽기 편하다.
4. CTA를 쓴다. 영상 마지막 장면의 단어를 그대로 가져온다.
5. 해시태그를 붙인다.
6. 아래 검수를 돌린다.

## 자체 검수
- 첫 줄만 읽어도 누구에게 무슨 이야기인지 알 수 있는가
- 항목이 5개 이하이고, 각 항목이 한 줄인가
- 항목이 기능이 아니라 **결과**로 쓰였는가
- 요구 행동이 2개 이하이고, 받을 것이 구체적인가
- 댓글 키워드가 한 단어이고, 영상에 나온 단어와 같은가
- 지어낸 수치·성과가 없는가
- 영상 자막 문장을 그대로 복사하지 않았는가

## 템플릿
```
[대상]이라면 이 [N]개는 무조건 [행동]하세요.

1. [이름] · [그걸로 얻는 결과 한 줄]
2. [이름] · [결과]
3. [이름] · [결과]
4. [이름] · [결과]
5. [이름] · [결과]

[행동1]하고 [행동2]에 [키워드] 남기면 [받을 것(내용물까지)]을 [경로]로 보내드려요.

#태그1 #태그2 #태그3 #태그4
```
