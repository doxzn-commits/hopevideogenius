# 런북 — 정보 전달 영상 한 편 만들기

> 요약: 대본만 있는 상태에서 mp4 까지 가는 확정 절차. "영상 만들어줘 / 새 에피소드 / 이 대본으로" 요청이 오면 이 문서대로 실행한다.

## 0. 입력 확인
- 대본(내레이션 문장들) — 없으면 먼저 받는다
- 토킹헤드 영상 파일(선택) — 있으면 `engine/public/` 에 넣고 spec 의 `talkingHead` 에 파일명만 적는다
- 레퍼런스 스타일 수치는 `factsheets/레퍼런스분석_claude스킬5_20260914.md`
- **외부 의뢰는 원문과 사실 출처를 labs 에 남긴다** — 연락처·주소·상호가 어디서 왔는지 없으면 납품 전에 대조할 수 없다. 영상에 넣는 사실은 받은 것만 쓴다

## 1. 대본 → 자막 쪼개기
- 한 자막 = **공백 제외 18자 이내**, 한 호흡. 넘으면 두 개로 나눈다(게이트가 막는다).
- 자막 하나당 최소 15프레임(0.5초) 노출. 강조할 단어 하나만 `hl` 로 지정한다.
- 한 씬 = 자막 1~3개, 18~240프레임(0.6~8초). 레퍼런스 평균 샷은 1.9초다.

## 3. 레이아웃·팔레트
- `split`: 상단 그래픽 + 하단 사람. 기본값. 자막이 카드 하단에 살짝 겹치는 게 의도된 모습.
- `full-graphic`: 사람 없이 그래픽만. 자막은 그래픽 아래.
- `full-face`: 사람 풀샷 + 자막. `face-only` 타입 전용.
- 팔레트는 **챕터마다 바꾼다**: ember / navy / violet / forest / pastel.

## 4. spec 작성
```bash
cp engine/specs/demo-repo-rules.json engine/specs/<이름>.json   # 참고용 원본
```
- `id` 는 영문·숫자·하이픈만 (Composition id 가 된다)
- **`engine/src/specs.ts` 에 import 한 줄을 추가한다** — 빠뜨리면 Studio 에 안 보인다(게이트가 잡는다)

## 5. 게이트 (생략 금지)
```bash
cd engine && npm run lint:spec
```
오류가 하나라도 있으면 렌더하지 않는다. 규칙과 수치는 `engine/src/spec/gate.ts` 의 `RULES` 가 원천이다.
게이트가 잡는 것: 씬 길이, 애니메이션이 끝나기 전 컷, 자막 길이·노출 시간·강조어, 리스트 행 수, 레이아웃 조합, spec 미등록, 레이아웃 겹침.

## 6. 미리보기
```bash
cd engine && npm run studio    # http://localhost:3000/<id>
```
타임라인에서 씬 길이를 눈으로 조정한 뒤, 바뀐 값을 spec 에 반영한다.

## 7. 렌더
```bash
cd engine && npx remotion render <id> out/<이름>.mp4
```
- 한 장만 확인: `npx remotion still <id> --frame=100 --scale=0.5 out/f.png`
- `out/` 은 커밋되지 않는다(.gitignore).

## 7.5 렌더 후 검수 (2026-11-05 추가)
수치 합격은 필요조건이다. 수치를 전부 통과한 렌더에서 보기 문제가 4건 나왔다(`labs/필름키오스크_구현기록_20261105.md`).
1. 만든 쪽 보고를 믿지 말고 렌더 파일로 다시 잰다. 측정 방식이 다르면 정지 비율이 2%p 안팎 달라진다. 비슷하면 같은 값으로 본다
2. 숫자 다음에 프레임을 본다. 1초 간격 시트로 전체를, 전환·문장 완성 구간은 연속 프레임으로
3. 물어볼 것: **완성된 상태가 읽을 만큼 오래 떠 있나**(쓰기·타이핑·공개 효과는 끝난 뒤부터 센다), 끝난 프레임 말고 도중 프레임은 괜찮나, 같은 요소가 샷마다 같아 보이나, 시청자가 실제로 필요한 정보(위치·연락처)가 그 크기로 충분한가
4. 눈으로 찾은 문제가 숫자로 적히면 게이트로 내린다(`FILM_T.inkHold` 가 이렇게 생겼다)

## 실패하는 방식 (겪은 것)
- 자막을 사람 얼굴 위 아무 데나 두면 읽히지 않는다 → 자막 Y는 레이아웃이 정한다. 직접 지정하지 마라.
- 씬 길이를 애니메이션보다 짧게 주면 동작이 잘린 채 컷된다 → 게이트가 `sceneEnd()` 로 판정한다.
- spec 만 만들고 `src/specs.ts` 등록을 빠뜨리면 Studio 에 아무것도 안 뜬다.
- 굵기가 하나뿐인 폰트에 부모의 `fontWeight` 가 상속되면 가짜 볼드로 뭉개진다 → 그 요소에서 굵기를 고정한다.
- 오브제를 화면 끝까지 채우면 다음 하드컷의 명암 대비가 죽는다 → 내용 높이에 맞추고 배경을 남긴다.
