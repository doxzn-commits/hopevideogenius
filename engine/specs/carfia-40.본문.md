# 카피아 데모 40초 — 게시물 본문

> 요약: `carfia-40.json` 영상에 붙이는 본문(캡션) 초안. 작성 규칙은 runbooks/소셜본문_작성절차.md.

## 본문 (그대로 복사)

```
차 살 때 딜러 몇 명이랑 얘기해 보셨나요?

카피아는 그걸 대신합니다.

1. 딜러 연락 · 전국 딜러에게 묻는 일을 카피아가 대신
2. 최저가 수집 · 흩어진 견적을 한 장의 비교표로
3. 시세 판단 · 이번 달이 싼 달인지까지 같이 확인
4. 비용 절감 · 출고까지 드는 비용을 줄이는 쪽으로
5. 상담 무료 · 받아보는 데 드는 비용 없음

carfia.co.kr 에서 이번 달 최저가를 무료로 받아보세요.

#카피아 #신차구매 #자동차견적 #최저가 #신차출고
```

## 왜 이렇게 썼나
- **훅이 질문이다.** 영상 첫 장면("BMW 이번 달 얼마지?")과 같은 고민을 글로 다시 던진다. 문장은 다르게 썼다.
- **항목이 기능이 아니라 결과다.** "딜러 연락 대행 서비스"가 아니라 "묻는 일을 카피아가 대신".
- **수치를 쓰지 않았다.** 절감률·시간 같은 숫자는 확인된 게 없어 적지 않았다.
  숫자를 넣으려면 실제 데이터를 받아야 한다(그때는 영상 결과 화면의 `예시` 라벨도 뗄 수 있다).
- **CTA 가 하나다.** 사이트 방문 하나만 요구한다. 댓글 키워드 방식으로 바꾸려면 영상 마지막 장면도 같이 바꿔야 한다.

## 바꿀 때
- 특정 차종으로 좁히려면 훅과 1번 항목에 차종을 넣는다(영상 4번 장면의 요청문도 같은 차종으로).
- 지역 한정이면 "전국" 을 그 지역으로 바꾼다 — 영상 자막·칩(`전국 딜러`)도 같이 바꿔야 말이 맞는다.
