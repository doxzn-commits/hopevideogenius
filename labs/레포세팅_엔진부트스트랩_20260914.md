# 레포 세팅 + 엔진 부트스트랩 (2026-09-14)

> 요약: 빈 폴더에서 지식 레포 + Remotion 엔진(씬 4종·게이트)을 세운 기록. 왜 이 수치·구조인지의 근거. "구조가 왜 이래 / 이 값이 왜 이거야" 질문에 연다.

## 결론 (먼저 읽을 것)
1. **레퍼런스 영상 1편을 프레임 단위로 분해한 수치가 엔진의 모든 상수의 출처다.** 감으로 정한 값은 없다 → `factsheets/레퍼런스분석_claude스킬5_20260914.md`
2. **자막 Y 좌표는 spec 이 아니라 레이아웃 상수가 정한다.** 씬마다 자막 위치를 자유롭게 주면 반드시 겹친다(실제로 겪음, 아래 3번).
3. **씬의 내부 타이밍은 `timelines.ts` 한 곳에서 계산하고, 컴포넌트와 게이트가 그 함수를 공유한다.** 그래서 "애니메이션이 끝나기 전에 컷" 이 기계 판정된다.
4. 이관할 기존 문서는 0개였다(빈 폴더 시작). 거대 지침 파일 분해·라우터화는 해당 사항 없어 CLAUDE.md 를 처음부터 라우터 형태로 썼다.

## 겪은 것

### 1. `full-graphic` 레이아웃에서 자막이 카드 위에 겹쳤다 — 코드로 고침
첫 렌더(frame 160, 250)에서 자막이 `PACK SLOT` 줄과 `1 MIN` 숫자를 덮었다.
원인: `full-graphic` 의 그래픽 영역이 260~1600, 자막 Y 가 1130 → 영역 한가운데.
- 고침: 그래픽 영역을 **200~1010** 으로 줄여 자막 위로 올렸다.
- 문서로 남기지 않고 **게이트에 박았다**: `checkLayouts()` — 사람이 없는 레이아웃(face === null)에서
  `graphic.bottom > captionY - CAPTION_HALF` 이면 오류. 좌표를 다시 만지다 겹치면 `npm run lint:spec` 이 즉시 잡는다.
- `split` 은 예외다. 레퍼런스에서 자막이 카드 하단에 **의도적으로** 겹친다(f_8.5 참조). 그래서 불변식 대상에서 뺐다.
- 이 과정에서 레이아웃 좌표를 `theme.ts`(remotion 의존) → `spec/layout.ts`(순수 숫자) 로 옮겼다.
  게이트 CLI 는 node 에서 도는데 remotion 을 import 하면 안 되기 때문이다.

### 2. `icon-flow` 의 "합쳐진 타일"이 칩 줄 위에 떴다 — 코드로 고침
`position: absolute; top: 180` 이 조상 중 positioned 요소를 못 찾아 엉뚱한 기준으로 잡혔다.
- 고침: 아이콘 줄 컨테이너(`height: 300`)를 기준으로 `inset: 0` + flex 중앙 정렬. 흩어진 아이콘 레이어와 같은 자리에 겹쳐 나타난다.
- 교훈: 씬 안에서 `position: absolute` 를 쓸 땐 기준 컨테이너를 그 씬 안에 명시한다.

### 3. 게이트 수치의 근거 (`src/spec/gate.ts` RULES)
| 값 | 근거 |
|---|---|
| sceneMinFrames 18 (0.6초) | 레퍼런스 최단 샷 0.6초 |
| sceneMaxFrames 240 (8초) | 레퍼런스 최장 샷 ≈6초 + 여유. 넘으면 정보가 정체된다 |
| captionMaxChars 18 (공백 제외) | 레퍼런스 최장 자막 17자("댓글에 스킬이라고 남겨주세요"), 60px·좌우 여백 60px 기준 한 줄 한계 |
| captionMinFrames 15 (0.5초) | 그 이하로는 읽히지 않는다 |
| titleNameMaxChars 14 | 모노 76px × 848px 카드 폭 |
| rowsMax 8 / iconsMax 6 | 카드 높이 1000px, 가로 960px 한계 |
