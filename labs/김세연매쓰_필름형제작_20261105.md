# 김세연 매쓰 키오스크 v2 — 필름형 엔진 구현과 제작 기록 (2026-11-05)

> 요약: 레퍼런스 6(B2 제품 필름형)을 엔진으로 내리고 그걸로 키오스크 광고를 다시 만든 기록. 무음 변형 film-kiosk 의 수치 근거, 측정 결과, 실패한 것. "키오스크 글자 크기 왜 이 값 / 필름형 왜 이렇게 만들었나 / 합격 기준 측정값" 에 연다.

## 결론
1. **필름형이 spec 으로 만들어진다.** 씬 7종(`select-hook` `film-text` `ai-answer` `notebook-steps` `ui-stage` `cta-marquee` `logo-outro`), `film` 레이아웃, `headline` 자막, `film-light`·`film-dark`, `brand`, `audio`, 프로필 2종, 게이트 규칙 전부 들어갔다. 시작 파일은 `engine/specs/template-product-film.json`, 사례는 `engine/specs/kimseyeon-math-kiosk-v2.json`.
2. **무음이어도 이 감도는 산다.** 명암 교대와 콜백이 서사를 나르기 때문이다. 대신 헤드라인이 메시지를 혼자 져야 해서 레퍼런스에 없던 헤드라인을 콜백 샷에 하나 넣었다("이번엔 내가 썼어요").
3. **가독성 편차는 프로필 값이다.** `FILM_TOKENS["film-kiosk"]` 에 있고 `checkLayouts` 가 불변식으로 막는다. 코드를 건드리지 않고 값만 바꾸면 게이트가 어긋남을 잡는다.
4. **측정은 `tools/measure_film.py` 한 줄이다.** 렌더 뒤 합격 기준을 다시 재고 싶으면 이걸 돌린다.

## 콘셉트에서 고친 것
- 콜백에 헤드라인 "이번엔 내가 썼어요" 추가(`captionSlot: peak`, y214). 무음이라 이 말이 없으면 공책이 왜 나오는지 지나가는 사람에게 안 닿는다. 사실 주장이 아니라 영상 안 서사다
- "내가 써야 해요"의 "써야"에 파란 손 밑줄(22f). 공책 밑줄 모티프를 급소에서 먼저 보여 준다. 흰 샷의 유일한 색이고 채도 픽셀 0.09%다
- 공책 3단계는 슬라이드 15f, 단계 표시(읽기·쓰기·설명)는 틀에 붙어 있어 움직이지 않는다

## 실패한 것
- **공책 손글씨 84px**: 멀리서 안 읽혔다. 112 로 키우고 획을 두껍게 했다
- **콜백 공책을 3줄 긴 문장으로**: 아래 절반이 빈 종이였다. 4줄로 끊고 140px·줄 간격 176 으로 키워 화면을 채웠다
- **답변 샷에서 pill 페이드 진입**: 하드컷 직후 빈 화면이 8프레임 나왔다. 컷 시점에 pill 이 이미 떠 있고 타이핑만 시작하게 바꿨다
- **`HandLine` 왼쪽 -2% 여백**: 쓰기 시작 전 점 하나가 새어 나왔다. 시작 전에는 `visibility: hidden`
- **밑줄 위치**: 밑줄 span 이 줄 높이를 상속해서 공책 줄과 겹쳤다. span 만 `lineHeight: 1.2`
- **손글씨 가짜 볼드**: 공책 줄의 fontWeight 600 이 손글씨로 상속돼 획이 뭉개지고 콜백 샷보다 굵었다. `HandLine` 에서 400 으로 고정
- **콜백 공책 전면 흰 종이**: 위 "4줄·140px" 로 화면을 채운 판이 총괄 검수에서 반려됐다. 흰 면이 50% 라 컷 MAD 129 였다. 112px·줄 간격 136 으로 줄이고 아래에 다크를 남겼다
- **쉘 heredoc 으로 파일을 한 번에 쓰기**: 윈도우 명령 길이 제한(ENAMETOOLONG)에 걸린다

## 손글씨 서체 비교
같은 문장을 나눔손글씨 펜, Gaegu, Hi Melody 로 놓고 봤다. **나눔손글씨 펜을 유지한다.** Gaegu 는 `÷` 글리프가 없어 풀이를 못 쓴다. 둘 다 자간이 벌어지고 획이 가늘어 아이 글씨 느낌이 강하고 멀리서 약하다. 펜은 가짜 볼드를 뺀 뒤 실제 펜 필기처럼 보이고 획이 가장 또렷하다. 다른 폰트 파일은 넣지 않았다.

## 오디오 시험
`audio.bgm`·`audio.voice`·`voiceAt` 를 테스트 톤(440Hz, 880Hz)으로 주입해 4초 렌더했다. AAC 트랙이 생겼고, 평균 음량은 BGM 만 있는 0~0.9초 −34.8dB, 내레이션이 겹치는 1.2~2.7초 −23.7dB 로 두 소스가 합쳐졌다. 테스트 파일은 지웠다. 키오스크 본 렌더에는 오디오 트랙이 없다.

- 실제 키오스크 화면에서 시청 거리별 가독성. 전부 렌더 프레임 기준 판단이다
- `product-film` 프로필은 내레이션 소재가 없어 실제 믹스·싱크를 시험하지 못했다
