# 카드형(지속 카드) 구현 (2026-10-16)

> 요약: 레퍼런스 2편(카드 1장 유지, 요청문→실행→결과)을 재현하기 위해 지속 카드·`prompt-run`·자막 스타일 2종을 엔진에 내린 기록과, 카드 안/밖 색 기준을 틀렸던 실수. "카드형이 어떻게 동작하나", "카드 안 글자색이 왜 고정이야"에 연다.

## 결론
1. **지속 카드는 "카드를 씬 밖에서 그리는 것"으로 구현했다.** 씬 컴포넌트는 카드 안 내용만 그린다.
   Series 안에서 카드를 그리면 씬이 바뀔 때마다 카드가 새로 등장(페이드)해 버린다. 틀을 밖으로 빼야 컷이 사라진다.
2. **카드 높이는 고정(1070px)이다.** 내용에 맞춰 늘리면 씬이 바뀔 때마다 카드가 들썩인다. 레퍼런스도 고정이다.
3. **카드 안과 밖은 색 기준이 다르다.** 카드 안은 항상 흰 바탕 → 글자색 고정(`CARD_INK`). 카드 밖 자막은 배경 기준(`palette.text`).
4. 결과 패널의 숫자는 **회색 막대로 가린다**(`Blank`). 지어낸 수치를 말하지 않으면서 "결과가 나왔다"를 보여주는 레퍼런스의 장치를 그대로 코드화했다.

## 구조
| 조각 | 위치 | 역할 |
|---|---|---|
| `layout: "card"` | `spec/layout.ts` `CARD`/`CARD_BODY` | 카드 좌표(85, 295, 910×1070, r42) + 안쪽 내용 영역 |
| `scene.card` | `spec/schema.ts` `cardSchema` | 머리글(app·glyph·status·index/total·tint). **씬이 바뀌면 이 값만 바뀐다** |
| `CardShell` | `components/CardShell.tsx` | 카드 틀. SpecVideo 가 Series **밖에서** 그린다 |
| `prompt-run` | `scenes/PromptRun.tsx` | 요청문 타이핑 → 툴 행(실행 중→✓완료) → 결과 패널 |
| 결과 패널 4종 | `schema.ts` `resultSchema` | thumbs / table / funnel / upload |
| `app-intro` | `scenes/AppIntro.tsx` | 큰 아이콘 + 역할 한 줄 |
| 자막 2종 | `components/Captions.tsx` | `plain`(외곽선 없음) / `overlay`(흰 글씨+외곽선). card 레이아웃은 기본 plain |

게이트에 추가한 규칙(`gate.ts`):
- `layout: "card"` 인데 `card` 가 없으면 오류 (카드가 빈 채로 유지된다)
- `prompt-run`·`app-intro` 는 `layout: "card"` 에서만
- 요청문 46자 초과 오류 — 말풍선 2줄(38px, 카드 폭 838px) 한계
- `card` 를 줬는데 layout 이 card 가 아니면 경고(무시된다는 뜻)

## 겪은 것

### 1. 사람 없는 레이아웃에 "토킹헤드 없음" 경고가 붙었다
게이트가 `layout !== "full-graphic"` 으로 판정하고 있어서 `card` 가 추가되자마자 오경고가 났다.
→ `LAYOUTS[layout].face !== null` 로 바꿨다. **레이아웃 목록을 늘릴 때 "그 외"로 판정하던 조건이 깨진다**는 교훈.

### 2. 카드 안 글자가 흰 바탕에 흰 글씨로 사라졌다
olive 팔레트의 `text` 는 밝은 색(#F2F3EE)인데, 카드 안은 흰 바탕이라 `statement` 가 보이지 않았다.
→ 카드 안쪽은 팔레트와 무관하게 `CARD_INK`/`CARD_SUB` 고정, 강조색만 팔레트의 `cardAccent`(흰 바탕용 어두운 톤)를 쓴다.

### 3. 그 수정이 카드 **밖** 자막까지 어둡게 만들었다
자막은 카드 밖이라 배경 기준이어야 하는데 `CARD_INK` 를 넘겨, 다크 배경에서 자막이 안 보였다.
→ 자막 색은 `palette.text`, 강조는 `palette.accent`. **"안/밖" 경계를 코드 주석으로 못 박았다.**

### 4. 자막 강조색이 노란색 고정이었다
`CAPTION.hl`(#FFD84D)이 하드코딩돼 있어 아이보리 배경에서 거의 안 보였다. → `hlColor` 를 주입받게 바꿨다.

## 남은 것
