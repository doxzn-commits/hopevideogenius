# 제품 데모 프로필 도입 (2026-09-14)

> 요약: 제품 데모 영상 기획 지침을 받아 문서/코드로 나눈 기록과, 글자 폭 넘침·커서 모양 결함을 고친 근거. "왜 문구가 15자 제한이야", "왜 프로필이 있어" 같은 질문에 연다.

## 결론
1. 지침 중 **숫자로 적을 수 있는 것은 전부 게이트로 내렸다.** 문서에는 판단이 필요한 것만 남겼다.
2. 글자 수 상한은 **손으로 정하지 않는다.** 폰트 최소 크기와 안전 영역 폭에서 계산한다(`layout.ts TEXT` → `maxCharsAt()`).
   컴포넌트는 같은 상수로 글자 크기를 줄이므로, 상수 하나를 고치면 렌더와 게이트가 같이 움직인다.
3. 화면 문구 "20자 내외"라는 지침은 **이 엔진에서는 틀린 수치였다.** 92px 두 줄 문구는 15자에서 화면을 넘는다.

## 겪은 것

### 1. 화면 문구가 3줄로 깨짐
92px 고정 크기로 "등록은 아직 직접 하시나요?"(15자)를 그리면 1080px 폭을 넘어 자동 줄바꿈됐다.
- 고침: `fitSize(글자수, base, min)` 으로 폭에 맞춰 축소 + `whiteSpace: nowrap`.
- 상한은 최소 크기에서 역산: 문구 `maxCharsAt(54) = 15자`, 자막 `maxCharsAt(44) = 19자`.
- **게이트와 컴포넌트의 글자 수 기준을 공백 포함으로 통일**했다. 게이트만 공백을 빼면 공백이 많은 문장이 통과한 뒤 넘친다.

### 2. 커서가 커서로 안 보임
CSS 삼각형을 -35도 회전시켰더니 "뒤로 가기 버튼"처럼 보였다. → SVG 포인터 path 로 교체하고 회전 제거.

### 3. 자막 없는 씬이 위로 쏠림
`full-graphic` 그래픽 영역(200~1010)은 자막 자리를 비워둔 값이라, 자막이 없는 `statement` 씬은 화면 위쪽에 붙었다.
→ 자막이 없고 사람도 없는 씬은 그래픽이 안전 영역까지(200~1800) 쓰도록 `SpecVideo` 에서 분기.

## 안 한 것
- 16:9 가로 지원(예시 의뢰는 16:9였다), 스마트폰 목업, AI 채팅창 씬, 오디오 → `KNOWN-GAPS.md`
- 전환 효과(0.4~0.7초)는 지침에 있으나 엔진은 하드컷만 한다. 레퍼런스도 하드컷이라 후순위로 뒀다.
